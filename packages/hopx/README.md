# @computesdk/hopx

HopX sandbox adapter for ComputeSDK. Run code and work with files in isolated Linux sandboxes.

## Install

```bash
npm install computesdk @computesdk/hopx
```

Configure the `hopx` adapter with `HOPX_API_KEY`.

See the [direct provider setup guide](https://github.com/computesdk/computesdk/blob/main/OPEN_SOURCE.md#direct-provider-mode) to use the adapter with `compute.setConfig()`.
