# @computesdk/agentuity

Agentuity sandbox adapter for ComputeSDK. Run code, work with files, and manage snapshots and checkpoints.

## Install

```bash
npm install computesdk @computesdk/agentuity
```

Configure the `agentuity` adapter with `AGENTUITY_SDK_KEY`.

See the [direct provider setup guide](https://github.com/computesdk/computesdk/blob/main/OPEN_SOURCE.md#direct-provider-mode) to use the adapter with `compute.setConfig()`.
