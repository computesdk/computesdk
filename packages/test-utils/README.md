# @computesdk/test-utils

Vitest suites and helpers for testing ComputeSDK sandbox, browser, and storage adapters.

## Install

```bash
npm install -D @computesdk/test-utils
```

Use `runProviderTestSuite` for sandbox adapters, `runBrowserProviderTestSuite` for browser adapters, and `runStorageProviderTestSuite` for storage adapters.
