# @computesdk/secure-exec

Local secure-exec adapter for ComputeSDK. Run JavaScript with a V8 runtime and an in-memory filesystem.

## Install

```bash
npm install computesdk @computesdk/secure-exec
```

Use the `secureExec` adapter with the secure-exec V8 binary on Linux x64. You can configure memory and CPU time limits.

See the [direct provider setup guide](https://github.com/computesdk/computesdk/blob/main/OPEN_SOURCE.md#direct-provider-mode) to use the adapter with `compute.setConfig()`.
