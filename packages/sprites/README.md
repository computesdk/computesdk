# @computesdk/sprites

Sprites sandbox adapter for ComputeSDK. Run commands and work with files in Sprites cloud sandboxes.

## Install

```bash
npm install computesdk @computesdk/sprites
```

Configure the `sprites` adapter with `SPRITES_TOKEN`.

See the [direct provider setup guide](https://github.com/computesdk/computesdk/blob/main/OPEN_SOURCE.md#direct-provider-mode) to use the adapter with `compute.setConfig()`.
