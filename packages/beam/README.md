# @computesdk/beam

Beam sandbox adapter for ComputeSDK. Run processes in cloud containers, work with files, and restore snapshots.

## Install

```bash
npm install computesdk @computesdk/beam
```

Configure the `beam` adapter with `BEAM_TOKEN` and `BEAM_WORKSPACE_ID`.

See the [direct provider setup guide](https://github.com/computesdk/computesdk/blob/main/OPEN_SOURCE.md#direct-provider-mode) to use the adapter with `compute.setConfig()`.
