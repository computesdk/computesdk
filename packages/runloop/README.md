# @computesdk/runloop

Runloop sandbox adapter for ComputeSDK. Run commands and work with files in Runloop Devboxes.

## Install

```bash
npm install computesdk @computesdk/runloop
```

Configure the `runloop` adapter with `RUNLOOP_API_KEY`.

See the [direct provider setup guide](https://github.com/computesdk/computesdk/blob/main/OPEN_SOURCE.md#direct-provider-mode) to use the adapter with `compute.setConfig()`.
