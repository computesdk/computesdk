# @computesdk/leap0

Leap0 sandbox adapter for ComputeSDK. Run code in cloud sandboxes for agents.

## Install

```bash
npm install computesdk @computesdk/leap0
```

Configure the `leap0` adapter with `LEAP0_API_KEY`.

See the [direct provider setup guide](https://github.com/computesdk/computesdk/blob/main/OPEN_SOURCE.md#direct-provider-mode) to use the adapter with `compute.setConfig()`.
